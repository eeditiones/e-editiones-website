The society promotes the use of **open standards** and **open source software** for digital editions. While digital editions may differ considerably in structure and content, there is great overlap in the basic technical functionality each edition must offer. Instead of reinventing the wheel, editions should be able to reuse existing building blocks in a modular way – achieving quick solutions at low cost, without being forced into a technical or scholarly corset.

All software development supported by the society is for the benefit of the general public and is available for further use as open source. New building blocks are created in a generic way, so other editions can easily adapt them to their requirements.

## Our Projects

- **[TEI Publisher](https://teipublisher.com/)** – a toolbox for building digital editions, consistently based on TEI and related standards such as ODD and the TEI Processing Model. The entire user interface consists of small web components complying with W3C standards, which can be recombined and reassembled as needed.
- **[Roaster](https://github.com/eeditiones/roaster)** – an OpenAPI router for eXist-db, powering the APIs behind TEI Publisher and many edition projects.
- Further tools and libraries maintained by the community can be found in the [e-editiones GitHub organization](https://github.com/eeditiones).

## How we work

Open source software cannot be created in isolation. It requires a constant exchange between developers and users who are familiar with the technical requirements of their respective edition projects. The society provides a stable and productive forum for this exchange and coordinates developments, so that existing funds and funding applications support sustainability from which all members derive long term benefits.
